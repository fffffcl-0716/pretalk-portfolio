# 面试前 Pretalk 智能备注

一个面向招聘 HR 工作流的 AI 信息提取项目案例。它将业务筛选通过后、正式面试前的候选人 Pretalk 通话，整理成一段可直接进入招聘系统的备注。

## 项目目标

- 降低 HR 从通话记录中手动整理信息的时间成本。
- 优先保留候选人的在职/离职状态、变动原因、现薪和期望薪资。
- 将分散的自然语言对话压缩为统一口径的一段中文备注。

## 公开展示内容

- `index.html`：可直接部署的作品集页面，包含项目背景、工作流、输出示例与实现逻辑。
- `portfolio-step*.jpg`：已脱敏的操作流程示意图。

## 实现设计

1. 接收智能通话记录或转写文本。
2. 提取状态、变动原因、薪资、其他机会和工作地点等事实信息。
3. 按候选人状态使用不同的变动原因规则：在职重点说明看机会原因，离职重点说明离职原因与离职后的状态。
4. 约束输出为约 100–150 字、日期开头、单段、可直接入库的中文备注。
5. 缺失信息不猜测；个人信息、示例数据和截图均经过脱敏处理。

## 隐私说明

本仓库仅展示项目设计与脱敏示例，不包含真实候选人资料、内部授权信息、生产环境地址或内部系统脚本。
